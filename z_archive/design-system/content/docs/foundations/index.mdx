This section will hold the canonical design tokens and cross-product rules.

## Initial token families

- Color
- Typography
- Spacing
- Borders and radius
- Elevation
- Motion
- Responsive behavior
- Focus and accessibility states

The implementation target is CSS custom properties surfaced through Tailwind utilities, so components and SurveyJS adapters can consume the same values.
