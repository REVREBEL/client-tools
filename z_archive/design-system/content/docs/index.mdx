This documentation is the source of truth for the Client Tools component system.

The design system is built for the shared application stack: **React, TypeScript, Tailwind CSS v4, and PostCSS**. Next.js hosts the current applications, while the component layer should remain portable enough for the Portal and the future React-based Onboard experience.

## Documentation workflow

Component documentation lives beside the design-system docs and deploys as a static GitHub Pages site. Interactive examples use `@fumadocs/story`, so we can exercise props and variants without maintaining a separate Storybook application.
