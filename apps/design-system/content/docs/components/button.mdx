## Props

- `variant`: `primary` (default), `secondary`, `accent`, `inverse`, `ghost`, `danger`
- `size`: `sm`, `md` (default), `lg`
- `href`: renders an `<a>` instead of a `<button>`
- `iconStart` / `iconEnd`: icons placed around the label, hidden from screen readers
- `fullWidth`: stretches to the container width
- Every native `<button>` or `<a>` attribute is passed through.

## Accessibility

- `type="button"` is the default, so a Button inside a form won't submit unless you set `type="submit"`.
- Focus shows a 3px cyan outline when using the keyboard.
- A disabled link gets `aria-disabled`, loses its `href`, and leaves the tab order.
- Icon-only buttons need an `aria-label`.
