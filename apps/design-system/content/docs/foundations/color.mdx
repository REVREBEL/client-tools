Each brand color has four steps: base, `-fade`, `-inverse`, and `-inverse-fade`. Use them as `bg-teal`, `text-teal-inverse`, `border-teal-fade`, or as `var(--rr-color-teal)` in CSS.

## Icon filters

To recolor a single-color SVG `<img>`, use `filter: var(--rr-filter-teal)`. There is one filter per brand color.
