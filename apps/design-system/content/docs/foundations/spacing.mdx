## Page and section padding

- `px-page-x` / `py-page-y`: 4rem / 3rem, 2rem on tablet, 1rem on mobile portrait.
- `py-section`: 8rem.

## Widths

- Page max widths: `max-w-page-xs` (900px) … `max-w-page-xxl` (1820px)
- Content widths: `max-w-content-xxs` (12rem) … `max-w-content-xxl` (70rem)
- Frames: `max-w-frame-sm` (1000px) … `max-w-frame-xl` (1600px)
- Icons: `size-icon-xxs` (1.5rem) … `size-icon-xxl` (3.75rem)
