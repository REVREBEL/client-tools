All tokens live in `@revrebel/tokens`. Webflow is the source of truth; the package mirrors its `base`, `color`, `typography`, and `size` collections.

## Setup in an app

```css title="app/globals.css"
@import "tailwindcss";
@import "@revrebel/tokens/index.css";
@source "../../../packages/ui/src";
```

## Layers

- **`--rr-*` CSS variables**: raw values, e.g. `--rr-color-teal`, `--rr-headline-lg`.
- **Tailwind classes**: `bg-teal`, `font-headline`, `text-headline-lg`, `gap-md`, `rounded-round`.
- **Composite type classes**: `type-h1`, `type-s3`, `type-eyebrow`, `type-label`.
