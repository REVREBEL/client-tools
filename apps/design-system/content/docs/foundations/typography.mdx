## Composite styles

Each `type-*` class sets family, size, weight, line height, and tracking together. Sizes are fluid between 16rem and 120rem viewports.

<TypeScale />

## Size-only classes

- `text-headline-xl` … `text-headline-xxs`
- `text-subheadline-xl` … `text-subheadline-xxs`
- `text-body-xxl` … `text-body-xxs`

Container-query sizes (inside an element with `container-type: inline-size`) are available as `var(--rr-r-headline-lg)`, `var(--rr-r-text-base)` and similar.
